# Абстракция RTOS поверх FreeRTOS

портирование и адаптация RTOS для работы поверх штатной FreeRTOS являющейся платформой по умолчанию для ряда аппаратных платформ:
- STM32 (Cortex-M)
- ESP8266/ESP32

требуется обеспечить бесшовную стыковку FreeRTOS, инструментов и HAL вендора аппаратной платформы, и массово используемых библиотек, предполагающих FreeRTOS в качестве базовой платформы

при этом программы специально разработанные для emC++ RTOS должны работать с минимальным слоем абстракции (в идеале только compile-time)
