# Code Generation
## Генерация кода

Автоматическое создание шаблонного кода на C/C++ на основе внешних описаний.

> Пример: Генерация структур данных, таблиц регистров, кода для обработки коммуникационных пакетов (например, из XML-описания) или целого [[hw/HAL|HAL]] (Hardware Abstraction Layer) из [[CMSIS]]-[[SVD]] файла.
