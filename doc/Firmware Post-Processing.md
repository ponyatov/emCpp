# Firmware Post-Processing
## Пост-обработка бинарных файлов

преобразования скомпилированных бинарных файлов прошивки, сборка дистрибутивных пакетов, рассылка через систему обновлений,..

> Пример: Добавление CRC-checksum, шифрование прошивки, разбиение бинарника на несколько частей для загрузчика (bootloader).
