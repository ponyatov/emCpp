# Build Automation
## Сборка проекта

## Python

Написание скриптов для управления сложным процессом сборки: вызов компиляторов и утилит (например, GCC), линкера, генерации файлов конфигурации, управление зависимостями.

Чаще всего используется в интеграции с [[GNU make]]/[[emCpp/CMake|CMake]]

> Пример: Скрипт, который собирает прошивку с разными флагами оптимизации и настроек по разным конфигурациям и заказчикам, прописанным в корпоративной базе данных (регистрация серийных номеров, криптографические ключи, пароли, конфигурация системы управления,..).
