# Обзор стандартов C++

> Какие фичи диалектов С++ критичны для наших задач ?

## [[C++17]]

Стандарт C++17 принес несколько важных возможностей для embedded-разработчиков:

- [[structured bindings]] для удобной работы с составными типами
	- Structured bindings позволяют декомпозировать объекты на отдельные переменные в одном выражении, что особенно полезно при работе с регистрами аппаратуры и протоколами связи.
- constexpr if для условной компиляции в шаблонах
- std::optional, std::variant, std::any для типобезопасных оберток
- inline variables для упрощения организации кода

## [[C++20]]

Революция в выразительности:
- Concepts для улучшенной проверки шаблонов
- Ranges для более выразительной работы с алгоритмами
- Coroutines для асинхронного программирования
- Modules для ускорения компиляции и лучшей инкапсуляции

## [[C++23]]

Новейший стандарт продолжает улучшать язык:
- std::expected для улучшенной обработки ошибок
- расширенные возможности constexpr
- std::mdspan для многомерных массивов
