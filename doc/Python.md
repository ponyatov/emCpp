# Python
## вспомогательный скриптовый язык

[[py/Python|Python]] очень популярен для написания разнообразных скриптов, выполнения задач автоматизации, когда реализовывать аналогичную функциональность на [[С++]] слишком сложно и дорого.

- требуется для работы [[Conan]]
- [[Code Generation|кодогенерация]] С/C++
- конвертация и преобразования форматов
- обработка разнообразных данных (текстовые, двоичные, СУБД)
- автоматизация тестирования оборудования
- ...

## Почему именно Python?

- **Низкий порог входа:** Инженеры, которые в основном пишут на C, могут быстро освоить Python для решения своих задач.
- **Огромная экосистема библиотек:** Для всего найдется готовый пакет (`pip install ...`).
- **Кроссплатформенность:** Скрипты работают на Windows, Linux и macOS без изменений.
- **Скорость разработки:** Написать рабочий инструмент можно за часы, а не дни.
    
**Итог:** Python стал "клеем" и "рабочей лошадкой" в мире embedded разработки.
